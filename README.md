# Codingal - Personal Goals Display

A Python program that collects user goals, displays a structured personal goal plan, and lists Python reserved keywords.

## Description
This project is created as part of the Codingal Python curriculum. It demonstrates user inputs, variable assignment, custom print separators/endings, string formatting, and working with Python's built-in `keyword` module.

## Program Features
- **User Inputs**: Prompts for name, goal skill, and target completion month
- **Goal Plan**: Formats and prints a structured personal goal schedule
- **Custom Formatting**: Demonstrates the `end` parameter in Python `print()` statements
- **Python Keywords**: Displays the complete list of Python reserved keywords using `keyword.kwlist`

## How to Run
```bash
python main.py
```
